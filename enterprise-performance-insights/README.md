# Enterprise Performance Insights

A simple dashboard showing revenue, profit and target attainment by department.

## Run
Open `index.html` in any browser. No installation needed.

## Files
- index.html - page structure
- style.css  - styling (light and dark themes)
- app.js     - sample data (DEPTS), calculations and chart rendering

## Use your own data
Edit the `DEPTS` object at the top of app.js (monthly revenue, target, cost and headcount per department).
